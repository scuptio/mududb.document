# 整数类型

```sql
INT      -- 32-bit signed
BIGINT   -- 64-bit signed
HUGEINT  -- 128-bit signed
```

`INT` 映射到内部 32 位有符号整数（`I32`）。`BIGINT` 映射到内部 64 位有符号整数（`I64`）。`HUGEINT` 映射到内部 128 位有符号整数（`I128`）。

SQL 中的所有整数字面量默认解析为 `I64`；超出 `I64` 范围的字面量会被解析器拒绝。解析器不针对列类型做范围检查：写入窄整型列的超宽值在运行时按截断转换规则处理（例如 `3000000000` 写入 `INT` 列会回绕为 `-1294967296`）。
